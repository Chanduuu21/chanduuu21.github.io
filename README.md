# Chandrasai Ettneni — Professional Portfolio

The source for [chanduuu21.github.io](https://chanduuu21.github.io/), a focused professional portfolio for Data Engineer, Analytics Engineer, Cloud Data Engineer, and Data Platform Engineer opportunities.

## What the site covers

- Current Data Engineer positioning and career summary
- Verified production outcomes and selected technical work
- Core data-engineering stack without skill ratings or keyword stuffing
- Experience across enterprise technology, manufacturing, and industrial robotics
- M.S. in Information Systems and AWS Data Engineer certification
- Direct links to GitHub, LinkedIn, email, and public project work

## Design principles

- Fast, dependency-free static HTML
- Responsive layout for desktop, tablet, and mobile
- Semantic structure, keyboard focus states, skip navigation, and reduced-motion support
- Open Graph, canonical, and structured-data metadata
- No proprietary code, confidential details, fake testimonials, or unsupported project claims

## Local preview

Open index.html in a browser, or run python -m http.server 8000 and visit http://localhost:8000.
